# Pattern catalog — the AI register, named

Each pattern: what it looks like → the fix. In Detect mode, name the pattern, quote the line,
state the fix in a few words. In Edit mode, apply the fix directly.

## Words to cut

**Banned outright** (level 1): delve, foster, leverage, utilize, facilitate, empower, streamline,
robust, cutting-edge, paradigm shift, game changer, tapestry, realm, beacon, multifaceted,
meticulous, intricate, paramount, transformative, elevate, embark, supercharge, harness (as a
verb), ever-evolving, seamless, pivotal, underscore. On level 2, the technical subset (`robust`,
`seamless`, `elevate`, `underscore`, `pivotal`, `harness`) is released.

**Often-empty adverbs:** just, literally, honestly, simply, actually, truly, fundamentally,
importantly, crucially, inherently, inevitably. Cut when they add nothing; keep when they carry
real emphasis, uncertainty, contrast, or the writer's spoken rhythm.

**Often-empty phrases:** it's worth noting, it's important to note, at the end of the day, when it
comes to, at its core, in today's world, the reality is, the truth is, in terms of, in order to,
going forward, let's dive in. Cut when they delay the point; an occasional one may stay when it is
recognizably the writer's voice.

## Named patterns (mechanical — a quote and a fix)

1. **Binary contrast.** "This is not X. It's Y." → state Y directly.
2. **Throat-clearing opener.** "Here's the thing", "Let me be clear" → delete; state the point.
3. **Faux-insight setup.** "What most people get wrong", "the part everyone misses" → cut the
   setup; let the claim stand alone.
4. **Colon reveal.** Noun phrase, colon, dramatic reveal ("The best part: it learns") → plain
   sentence. Colons are for lists, labels, and quotes.
5. **Superficial analysis.** Trailing "-ing" clause pretending to explain ("…, highlighting the
   team's commitment") → replace with the actual consequence, or cut.
6. **Importance puffery.** "Marks a pivotal moment", "stands as a testament" → state the fact;
   the reader judges whether it matters.
7. **Interpretive metadiscourse.** "The key point is", "as you can see", "this distinction
   matters" → delete, or replace with the support that would earn it.
8. **Weasel attribution.** "Experts agree", "studies show" → name the source or ask for one;
   never invent.
9. **Fake-strong verb.** "Serves as a centralized hub for" → "tracks X, Y, Z in one place".
10. **Synonym cycling.** Agent/assistant/tool rotating for the same thing → repeat the clear word.
11. **Negative listing.** "Not X. Not Y. Z." → say Z.
12. **Dramatic fragmentation.** "X. And Y. That's it. That's the whole thing." → complete
    sentences.
13. **Robotic rhythm.** Identical sentence shapes and stacked punchy fragments → vary only when
    it serves the point.
14. **Rhetorical setup.** "What if I told you…", "Plot twist:", self-answered Q&A → drop it, make
    the point.
15. **Fake-profound kicker.** The final aphorism/mic-drop → DELETE it (never rewrite it into a
    better metaphor, never preserve the rhythm); end on the clearest concrete sentence already in
    the draft.
16. **Summary-recap ending.** "In conclusion", a final paragraph restating the piece → end on the
    last concrete point or next action; the reader was just there.
17. **Formatting slop.** Emoji headings, mid-sentence bold for emphasis, bullets where two
    sentences read better, headers over two-sentence sections → format follows content.
18. **Em-dash crutch.** Em dashes as default rhythm → none in short copy; one or two in long
    drafts when they clearly beat commas or parentheses; never clusters. The spaced double hyphen
    (` -- `) is worse: it signals a bad cleanup.

## Judgment patterns (no regex catches these — they need reading)

1. **Negation pivot.** The "it's not about X — it's about Y" move as a structural tic, today a
   stronger tell than any vocabulary item.
2. **Triadic everything.** Three examples, three adjectives, three clauses, everywhere. Two or
   four is often honest; three every time is a generator's habit.
3. **Five-paragraph-essay shape.** Intro-three-points-conclusion imposed on content that did not
   ask for it.
4. **Uniform paragraph length.** Every paragraph the same size is a generated fingerprint; real
   prose breathes.
5. **Synthetic balance.** "On one hand… on the other…" applied to a question the writer actually
   has a position on.
6. **Hollow confidence.** Assertive tone with no falsifiable content under it.
7. **Hedging stacks.** "Might potentially, in some cases, depending…" — pick a position or state
   the real uncertainty once.
8. **Interchangeable copy.** The paragraph passes the portability test in reverse: it could ship
   in any competitor's README unchanged. Rewrite around the one thing only this subject can claim.
